# 🌍 AzureJirani: Your AI Study Buddy for AZ-900

> An AI-powered, context-aware study assistant designed to help learners across Africa master Microsoft Azure Fundamentals (AZ-900) through relatable local analogies[span_3](start_span)[span_3](end_span).

---

## 💡 The Problem
Cloud computing concepts (like CapEx vs. OpEx, high availability, and global infrastructure) often feel abstract and overly technical for beginner learners studying for the AZ-900 exam[span_4](start_span)[span_4](end_span). 

## 🚀 Our Solution: AzureJirani
**AzureJirani** bridges the gap by translating dense cloud definitions into everyday, relatable scenarios—such as running a bodaboda business or managing mobile money infrastructure—making cloud concepts instantly click[span_5](start_span)[span_5](end_span).

## 👥 Target Users
- Beginners and self-taught developers across Africa preparing for the Microsoft AZ-900 certification[span_6](start_span)[span_6](end_span).
- Learners looking for interactive, conversational, and scenario-based explanations rather than static textbooks.

## ✨ Key Features
- **Localized Analogies Engine:** Translates Azure architecture and financial models into everyday African business and transport examples[span_7](start_span)[span_7](end_span).
- **Interactive Quick-Start Chips:** Instant prompts for core syllabus areas like IaaS/PaaS/SaaS, Regions, and Availability Zones[span_8](start_span)[span_8](end_span).
- **Scenario-Based Practice:** Custom-generated practice questions with step-by-step explanations[span_9](start_span)[span_9](end_span).

## 🛠️ Tech Stack & Vibe Coding Tools
- **Bolt.new** – For rapid full-stack scaffolding and UI generation[span_10](start_span)[span_10](end_span).
- **Claude.ai / LLM Integration** – For strict prompt engineering and natural tone control[span_11](start_span)[span_11](end_span).
- **React & Tailwind CSS** – For a clean, mobile-first user interface.
